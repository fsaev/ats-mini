The firmware is now built with ESP-IDF and CMake instead of the Arduino framework. The libraries are git submodules: the TFT_eSPI display library is replaced by LovyanGFX, the SI4735 library by a native driver, and the Arduino BLE and web server libraries by the ESP-IDF NimBLE and HTTP server. The compile-time options are now `menuconfig` options, see the development documentation.
